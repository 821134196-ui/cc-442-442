# 社区雨水口清掏管理平台

维护道路区段、雨水口编号与堵塞等级，覆盖巡查建单、警戒范围、派工调度、
开盖→清掏→冲洗→复位四道工序、前后照片、淤泥袋数、车辆过磅交接、逐点验收与居民反馈的全流程。

- **零依赖**：仅使用 Python 3.10+ 标准库（`http.server` + `sqlite3`），无需 pip 安装
- 数据写入 **SQLite**，现场附件落到本地 **uploads/** 目录
- 进程内任务生成**暴雨前复查提醒**，车辆过磅由**模拟适配器**返回结果
- 前端为原生 HTML/CSS/JS，浅灰路网底色 + 雨水蓝 + 安全橙

## 一条命令启动

```bash
python3 -m app
```

自动重置并载入本地样例（堵塞待派工、验收退回整改、已完成各一张，另有暴雨加急单与作业中单），
随后启动服务：

```
http://127.0.0.1:8000
```

可选参数：`--port 8123`、`--host 0.0.0.0`、`--db data/platform.db`、`--uploads uploads`、
`--no-seed`（保留现有数据启动）。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

27 个用例覆盖：派工冲突（含 5 线程并发）、步骤/材料缺失门禁、相邻合单边界、
合单逐点验收、重量修订审计、五类角色越权、六个应急入口、暴雨提醒触发。

## 核心规则

- **工序门禁**：开盖→清掏→冲洗→复位必须顺序记录，不可跳过、不可重复。
- **申请验收材料**：每个点位的前照片、后照片、淤泥袋数、复位检查（含四工序）齐全才可申请，
  缺失项逐个列明并拦截（422）。
- **验收**：逐点位通过/退回（合单**只合派车、不合验收**）；通过后该点位恢复畅通，
  全部点位通过工单才完成；退回后**继续沿用原工单**整改、重新派工/申请。
- **派工冲突**：调度员派工时对同一班组的时间窗做半开区间重叠判断，
  写事务加锁（`BEGIN IMMEDIATE`），并发分配时恰好一张成功。
- **相邻合单**：同一路段或直线距离 ≤ 120m（示意坐标）判为相邻，连通分量不相邻则拒绝（422）。
- **重量修订**：仅主管可修订，必须写明原因，记录修订人、时间并产生通知。

## 六个独立处理入口（页面右上“⚑ 应急处理”）

暴雨前加急（生成提前 2 小时复查提醒）、井盖破损（自动建处置单+扩大警戒+标记井盖）、
积水反涌、淤泥遗撒、车辆未到（标记车次后改派车辆）、照片缺失（补拍后事件自动关闭）。

## 角色

顶栏右侧可切换身份（样例用户）：巡查员、调度员、班组、验收员、主管；
后端对每个写操作做角色校验（403）。
