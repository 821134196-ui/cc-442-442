# 社区雨水口清掏管理平台

面向社区防汛班组的雨水口巡查—派工—清掏—验收闭环管理。零三方依赖：仅使用 Python 3.10+
标准库（`http.server` + `sqlite3`）与原生 HTML/CSS/JS。

## 一条本地命令启动

```bash
./run.sh                 # 等价于 python3 -m app --reset
# 或：python3 -m app --reset --port 8000
```

启动时自动建库并载入三类样例：**堵塞待派**（WO-BLOCK-01/02，含警戒范围与暴雨加急）、
**验收退回**（WO-REJECT-01，沿用原工单）、**已完成**（WO-DONE-01，含重量修订审计）。
打开 http://127.0.0.1:8000 ，右上角切换身份（巡查员/调度员/班组/主管/验收员）。

## 六个页面

| 页面 | 内容 |
|---|---|
| 片区点位图 | 浅灰路网底 + 雨水蓝/安全橙；点位只显示编号与堵塞等级；点击打开侧栏再展开照片与工序 |
| 巡查列表 | 建单、划警戒范围、六类专项入口（暴雨前加急/井盖破损/积水反涌/淤泥遗撒/车辆未到/照片缺失）、居民反馈 |
| 班组日程 | 派工/合单派车甘特、同班组时间冲突拦截、合单橙色标记 |
| 清掏记录 | 开盖→清掏→冲洗→复位依次记录、淤泥袋数、前后/复位照片上传、车辆到场/未到/模拟过磅、主管重量修订、验收门禁清单 |
| 车辆交接 | 到场/未到登记、合单整组改派、模拟地磅过磅、主管修订（原因必填+审计） |
| 验收台账 | 4:3 固定比例前后照片**并排**画框（`object-fit:contain` 不裁井口边缘）；窄屏 ≤860px 自动**上下对照**；通过后雨水口恢复正常，退回沿用原工单 |

## 核心规则

- **派工冲突**：写操作在 `BEGIN IMMEDIATE` 事务内串行化，同一班组时段重叠（含并发请求）返回
  409 `schedule_conflict`；首尾相接与跨班组不冲突。
- **相邻合单**：同一道路区段且平面距离 ≤150m 才可合并派车；**只合并派车，不合并验收**——
  每个工单按各自的四工序、袋数、前后照片独立门禁、独立验收。
- **验收门禁**：四步工序齐全、淤泥袋数已登记（中重度堵塞袋数不得为 0）、清掏前/后照片与
  复位检查照片齐全，才能申请验收。
- **退回闭环**：验收退回后工单号不变、状态置 rejected，可重新派工继续处理；验收通过后
  雨水口回到 normal。
- **重量修订**：仅主管，必须填写原因，原值/新值/原因/操作人写入 `weight_revisions` 审计表。
- **暴雨提醒**：进程内守护线程定时触发，落库 `reminders`，页面顶部条幅展示并可手动检查。
- **模拟过磅**：`app/adapters.py` 按派工号返回确定性净重（毛重/皮重/净重）。
- 附件落到本地 `uploads/photos/`，样例图片在 `uploads/sample/`（程序自动生成的 SVG）。

## 数据与接口

- SQLite：`data/stormwater.db`（14 张表，schema 见 `app/db.py`）。
- JSON API：`GET /api/map`、`/api/orders`、`/api/schedule`、`/api/handovers`、
  `/api/acceptances`、`/api/reminders`；写接口均需 `X-Username` 请求头（本地样例账号）。
- 本地样例账号：`inspect` / `dispatch` / `super` / `accept` / `crew1` / `crew2`。

## 测试

```bash
python3 -m unittest tests.test_platform -v   # 37 个用例
```

覆盖：派工时间冲突（含双线程并发）、工序/照片/袋数/复位缺失门禁、合单边界（跨区段/超距/
已验收/合单独立验收/合单整组改派）、重量修订（角色+原因+审计）、五类角色权限矩阵，
以及退回沿用原工单、暴雨提醒、HTTP 401/403/409 与 multipart 照片上传集成。

## 目录结构

```
app/
  config.py     常量（合单距离、工序、角色、专项类型）
  db.py         SQLite schema
  seed.py       堵塞/退回/已完成样例 + 本地联系人和样例照片
  services.py   业务规则（冲突/合单/门禁/修订/反馈/提醒）
  adapters.py   模拟地磅适配器
  reminders.py  进程内暴雨复查提醒
  auth.py       X-Username 角色鉴权
  server.py     stdlib HTTP 服务 / multipart 解析 / 静态与附件托管
  web/          六个页面（单页 + SVG 地图）
run.sh          一条本地启动命令
tests/          unittest 规则测试
```
